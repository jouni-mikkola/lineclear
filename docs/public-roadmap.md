# Roadmap

What Lineclear is for is in [idea.md](idea.md). This is the short public plan; the detailed step list the rules read
is kept by the maintainers.

## Now

- A clean install on Linux from the README alone, with `lineclear doctor` naming any problem and its fix.
- One product name, one CLI, one web UI and one data folder on every machine.
- Rules that start, review and merge steps by themselves, with waits that name their cause.

## Next

- Finish the own server in `server/`, which still follows Lineclear 2.0 inside.
- A merge lane that keeps main green without the board.
- A web UI that meets the bar in [design.md](design.md) on every view.

## Later

- More machines over SSH with one Home and one Inbox.
- Other systems than Linux.

Ideas and bugs are welcome as issues; see [CONTRIBUTING.md](../CONTRIBUTING.md).
